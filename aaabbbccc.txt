  Część 2 — Kolejność wypełniania (sequential + parallel)

  Aktualny przewodnik dla studenta w bazie (STUDENT_WORKFLOW_DATA) pokazuje tylko kroki studenta. Pełen obieg z udziałem
  innych ról wygląda tak:

  ┌─────────────────────────────────────────────────────────────────────────┐
  │  FAZA 0 — Pre-setup                                                     │
  │  • zopz  → Zał. 9 (oświadczenie instytucji)        ← startuje proces    │
  │  • uopz  → Zał. 2 (ramowy program)        [może żyć statycznie obok]    │
  └─────────────────────────────────────────────────────────────────────────┘
                                ↓
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  FAZA 1 — Przygotowanie praktyki   (rozgałęzienie: ścieżka A lub B)     │
  │                                                                         │
  │  ┌── ŚCIEŻKA A (standardowa praktyka) ──────────────────────────────┐   │
  │  │   1. student → Zał. 1   (recenzja: uopz)                         │   │
  │  │   2. student → Zał. 2a  (recenzja: zopz)    [po Zał. 1]          │   │
  │  │   3. uopz    → Zał. 3   skierowanie (UOPZ tworzy)                │   │
  │  └──────────────────────────────────────────────────────────────────┘   │
  │                                                                         │
  │  ┌── ŚCIEŻKA B (zaliczenie na podstawie pracy/stażu) — OPCJONALNA ──┐   │
  │  │   1. student → Zał. 4b  (recenzja: uopz)                         │   │
  │  │   2. uopz    → Zał. 4a  (odpowiedź na 4b — Decyzja Dyrektora)    │   │
  │  └──────────────────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────────────────┘
                                ↓
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  FAZA 2 — Realizacja praktyki   (tylko ścieżka A)                       │
  │  • student → Zał. 6 (dziennik)  → recenzja: zopz   [codziennie]         │
  └─────────────────────────────────────────────────────────────────────────┘
                                ↓
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  FAZA 3 — Po praktyce   (równoległe wypełnianie, 4 wątki)               │
  │                                                                         │
  │  ║ student → Zał. 7 (ścieżka A) lub Zał. 7a (ścieżka B)                 │
  │  ║ student → Zał. 5 (ankieta anonimowa)                                 │
  │  ║ zopz    → Zał. 3 cd. — ocena zakładowa + Zał. 4                      │
  │  ║ uopz    → Zał. 3 cd. — ocena uczelniana + ocena sprawozdania         │
  └─────────────────────────────────────────────────────────────────────────┘
                                ↓
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  FAZA 4 — Zaliczenie końcowe (wspólna dla A i B)                        │
  │  • dziekanat → Zał. 8 (protokół + K = 0,4E + 0,1S + 0,2U + 0,3Z)        │
  └─────────────────────────────────────────────────────────────────────────┘

  Co MOŻE iść równolegle:
  - Zał. 9 (zopz) i Zał. 2 (uopz) — niezależne
  - W Fazie 1: Zał. 1 i Zał. 2a — można równolegle (oba wypełnia student)
  - W Fazie 3: wszystkie 4 wątki niezależne (student/zopz/uopz)

  Co MUSI iść sekwencyjnie:
  - Zał. 9 → Zał. 1 (potrzebny nr porozumienia)
  - Zał. 1 → Zał. 3 (Zał. 3 pobiera nr porozumienia)
  - Zał. 4b → Zał. 4a (4a jest odpowiedzią na wniosek)
  - Wszystko → Zał. 8 (protokół końcowy musi mieć S, U, Z, E)

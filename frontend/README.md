# Frontend

Frontend projektu jest renderowany przez Flask/Jinja2, dlatego jego kod
wykonywalny znajduje się w katalogach:

- [`../templates`](../templates) - widoki HTML,
- [`../static/css`](../static/css) - arkusze stylów,
- [`../static/js`](../static/js) - walidacja i klient REST,
- [`../static/images`](../static/images) - zasoby graficzne.

Nie ma osobnego procesu `npm` ani bundlera. Instrukcja architektury,
uruchomienia i testowania znajduje się w
[`../documentation/FRONTEND.md`](../documentation/FRONTEND.md).

Raport testów etapu 10A:
[`../documentation/testy-ui/ETAP_10A_TESTY_UI.md`](../documentation/testy-ui/ETAP_10A_TESTY_UI.md).
